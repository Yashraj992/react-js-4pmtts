What is react js props?

Ans:

  • Props stands for properties
  • props is passed in any function as arguments or parameters i.e called properties.
  • props is used to pass data in another components using props.
  • props is also access html elements using attributes.
  • in function use as a arguments and in html use as a attributes in props.
    •             function App(props)
            {
                return(
                    <>
                    
    My name is {props.name}
    
                    
                )
            }

    Note:

  • props does not update and data on run time.
  • props only send data on components to another components but does not update it.
  • props is immutable means can not changed or update data using props one components to another components.
